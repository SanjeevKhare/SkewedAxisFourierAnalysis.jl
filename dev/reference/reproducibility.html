Reproduce the documentation ​

The documentation is built with Documenter, DocumenterVitepress, Literate, and CairoMakie. Tutorial code, assertions, and figures share a single source: the scripts in docs/examples/.

Build everything ​

sh
git clone https://github.com/SanjeevKhare/SkewedAxisFourierAnalysis.jl.git
cd SkewedAxisFourierAnalysis.jl
julia --project=docs -e 'using Pkg; Pkg.develop(path=pwd()); Pkg.instantiate()'
julia --project=docs docs/make.jl

The first build downloads Julia packages and VitePress dependencies. Later builds reuse local caches. The rendered website is written to docs/build/1/; serve that directory beneath /SkewedAxisFourierAnalysis.jl/dev/ for a faithful deployment preview.

What runs during a build ​

ScriptResult and numerical check
docs/examples/synthetic.jlKnown two-mode recovery, error below 10⁻¹², threshold sweep, saved coefficients
docs/examples/digitization.jlSynthetic RGB calibration with RMSE below 0.01; repository image conversion checked for finite values
docs/examples/reconstruction.jlInverse-coordinate checks at 60°, 90°, and 120°, maximum error below 10⁻¹²

These are numerical checks of the examples. The image conversion check does not validate the original material's scale or the quality of a harmonic fit to experimental data.

Source and generated files ​

Edit tutorial prose and code in docs/examples/*.jl. Literate creates the corresponding tutorial pages; do not edit generated Markdown. Figures are regenerated in docs/src/assets/figures/; downloadable scripts and coefficients are staged in docs/src/public/downloads/.

The coordinate diagram is maintained in docs/src/assets/coordinates.svg; the hero in docs/src/public/ is generated by docs/illustrations.jl. Theme and navigation live in docs/src/.vitepress/. General guide pages are ordinary Markdown under docs/src/guide/.

Publication ​

The existing GitHub Pages site serves the main-branch docs under /dev/. CI builds the complete documentation, runs its example assertions, and publishes on main through DocumenterVitepress. Pull requests build without publishing. Local builds publish only if DOCS_DEPLOY=true is deliberately set and valid deployment credentials are available.

The root address continues to redirect to /dev/. Legacy tutorial and API directory URLs redirect to their corresponding new pages.
